# Reflection: How the browser loads tasks.html

First, the browser downloads the `tasks.html` file and reads the HTML from top to bottom to build the structure of the page, such as the heading, the form fields, the Add button and the empty task list. While it reads the `<head>`, it finds the link to `style.css`, downloads it and uses the CSS rules to give the page its colours, fonts, spacing and layout. At the end of the `<body>` it finds the `<script>` tag, so it downloads `tasks.js` and runs the JavaScript only after the HTML elements already exist. The JavaScript first uses localStorage to read the saved list of tasks from this browser, turns the JSON text back into a list and shows every task on the page. After that, the JavaScript waits for the user to click "Add", then checks the input, saves the new task in localStorage and updates the list without reloading the page.
