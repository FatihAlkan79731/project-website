# Reflection: Git versus GitHub

Git is a free version control program that I install and run on my own computer, while GitHub is a website that keeps copies of Git repositories online. With Git I work in the terminal and use commands such as `git add`, `git commit`, `git branch` and `git merge` to save and organise the history of my project, even without an internet connection. GitHub adds the online part of the work, because pull requests, code reviews, comments and GitHub Pages exist only on the website and are not Git commands. The two tools are connected by `git push` and `git pull`, which send my commits to GitHub and bring my teammates' commits back to my computer. For teamwork we need both, because Git keeps every person's changes safe and separate on branches, while GitHub gives the team one shared place to review those changes and merge them into `main`.
