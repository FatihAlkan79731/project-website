# Module 5 Homework: Authentication vs Authorization

Authentication is the step where the system checks who the user really is, for example by asking for something only that person knows. In my Student Task Manager, logging in to Supabase with an email and a password is authentication, because Supabase checks these details and then knows which student is using the page. Authorization is the next step, where the system decides what this known user is allowed to see and change. In my project, the RLS policy "users manage own tasks" is authorization, because the database compares `auth.uid()` with the `user_id` of every row and lets a student read, update or delete only their own tasks. So if I am logged in and try to open or delete another student's task, I am authenticated but not authorized, and the database returns nothing and changes nothing for that row.
